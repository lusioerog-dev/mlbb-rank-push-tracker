## Schema and calculations

No new SQL migration. The existing private Supabase JSON workspace stores optional structured starting rank, per-match delta and placement checkpoint. Old records and backups remain accepted; manually typed historical rank text is retained for compatibility. Current rank is derived rather than redundantly stored. The existing source field already identifies manual or screenshot-reviewed records.

Daily points use every ranked match in chronological order, grouped in the configured timezone. Days without matches are omitted. Individual-game mode retains the starting baseline. Both views use the same canonical records. Unknown deltas produce gaps. Below Mythic, continuous season progress is labelled separately from stars within the current division. Player playtime sums known durations and marks partial coverage. Classic games affect appropriate player/game statistics but never account rank.

## Manual setup before the season

Sign into the published tracker with the provisioned account and create a shared tracker from the existing local matches. The other player needs a separate confirmed login and an invitation to the same workspace. General email signup/recovery remains disabled until SMTP is configured.

Before the new season: export a backup. After the in-game reset and before the first ranked match, select **Start a new shared season**, then **Settings**, and enter the actual starting rank/division/stars and season name. Save and invite the other player to this new workspace. Reset mapping is deliberately not guessed. Mythic placement requires a confirmed star checkpoint when reached; see the rank-rules document for the exact limits.
